# NEON STACK 실행 안내

이 프로젝트는 별도 설치나 빌드 과정이 없는 테트리스 웹앱입니다. `index.html`은 플레이 안내가 있는 랜딩 페이지이고, `game.html`은 실제 게임 화면입니다.

줄을 지워 레벨이 오를수록 블록의 자동 낙하 속도가 빨라집니다.

## 브라우저에서 바로 열기

1. 프로젝트 폴더에서 `index.html`을 브라우저로 엽니다.
2. 랜딩 페이지의 **플레이 시작** 버튼을 누릅니다. 바로 게임 화면을 열려면 `game.html`을 직접 열어도 됩니다.
3. 게임 화면의 **게임 시작** 버튼을 누릅니다.

## 로컬 웹 서버로 접속하기

브라우저에서 로컬 웹 주소로 열고 싶다면 Python 3가 설치된 환경에서 프로젝트 폴더를 연 뒤 서버를 실행합니다.

macOS 또는 Linux:

```sh
python3 -m http.server 8000
```

Windows:

```powershell
py -m http.server 8000
```

서버를 실행한 컴퓨터에서 브라우저로 다음 주소에 접속합니다. 랜딩 페이지에서 **플레이 시작**을 누르면 게임 화면으로 이동합니다.

```text
http://localhost:8000
```

서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 조작 방법

| 키 | 동작 |
| --- | --- |
| ← / → | 블록 좌우 이동 |
| ↑ | 블록 회전 |
| ↓ | 블록 빠르게 내리기 |
| Space | 블록 즉시 떨어뜨리기 |

휴대폰과 태블릿에서는 게임판 아래의 화면 버튼을 누릅니다. 좌우 이동과 빠른 낙하 버튼을 길게 누르면 계속 움직입니다.

게임을 시작하면 WebAudio로 합성한 코로베이니카 BGM이 재생됩니다. 화면 상단의 음악 버튼으로 켜거나 끌 수 있습니다.

게임이 끝나면 **다시 플레이** 또는 **다시 시작** 버튼으로 새 게임을 시작합니다. 점수와 지운 줄 수는 게임 화면 오른쪽에 표시됩니다.

## 프로젝트 구성

- `index.html`: 게임 소개와 조작 안내가 있는 랜딩 페이지
- `game.html`: 반응형 테트리스 게임, 화면 터치 조작, WebAudio BGM
- `game-logic.js`: 게임에서 사용하는 회전 로직
- `tests/`: Jest 유닛 테스트
- `plan.md`: MVP 구현 계획

외부 라이브러리나 백엔드 서버는 필요하지 않습니다. 로컬 서버 실행 방법은 선택 사항입니다.
